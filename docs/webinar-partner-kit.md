## 6. 個別面談の進め方（30分）

1. ご本業・保有資格・お客様の層をうかがう（5分）
2. ご質問にお答えする（15分）。**条件は書面のとおり**で、口頭だけの約束はしない
3. 概要書面の受け取り方をうかがう（5分）
   - 「概要書面を**メールで**お受け取りいただいてよいですか」と確認し、**了承をいただいた日時と方法を記録**する
   - メールを望まれない方には、紙でお送りする
4. 次の一歩の確認（5分）
   - 概要書面をお送りする日
   - ご質問の窓口

> **してはいけないこと**
> - 収入を約束しない（「すぐ○万円」「必ず」など）
> - 不利なこと（費用・終え方）を隠さない
> - その場で決めるよう急かさない
> - 事実と違うことを言わない

## 9. ご契約のご案内と、同意のあと

1. **運営**：コンソールの「サポート管理」→「契約書の送付」から、**パートナー契約**を送る（相手のメールアドレスあて）。
2. **お相手**：届いたリンクを開くと、TsuguAi のスタート画面に契約書の全文が出る。
   - 全文を読み、お名前を入れて「同意して契約する」。
   - そのまま登録（メール・パスワード）すると、認定パートナーとして使い始められる。
   - **契約を送ったのと同じメールアドレスで登録**していただく（違うアドレスだと役割が付かない）。
3. **運営**：同意の知らせ（アプリ内・メール・LINE）が届いたら、**契約書面をメールでお送りする**（同意した全文の控え。同じリンクからも見返せる）。
4. **お相手**：研修プログラム（全5章）を受ける。修了で Lv.1 認定。

## 10. 弁護士に確かめていただくこと（公開の前に）

> 認定パートナーは、利用料（基本料・AI利用料）をご負担いただいたうえで、顧問の仕事と報酬を得る形です。
> 特定商取引法の「業務提供誘引販売取引」にあたる前提で、次を確かめてください。

- [ ] **該当するかどうか**と、あたる場合の対応一式
- [ ] **広告の表示事項**（告知文・スライド・募集ページ・特定商取引法に基づく表示）と、**誇大な表示**にあたらないか
  - 特に「計算の例」の頁、「前払いはありません」の表現
  - 「法人営業の壁」の頁（法人の成約が増えると受け取られない書き方か）
- [ ] **概要書面**の記載事項。**メールで渡すこと**への了承の取り方と、その記録の残し方
- [ ] **契約書面**の交付
  - スタート画面での同意と、同意後のメール送付で足りるか
  - 記載事項に漏れがないか
- [ ] **クーリング・オフ**の期間と書き方
  - 業務提供誘引販売取引なら、法定の書面を受け取った日から20日間
  - 書面の記載と、画面・スライドの案内が一致しているか
- [ ] **勧誘のときの禁止行為**（不実告知・事実の不告知・威迫など）を、面談の進め方（6）に漏れなく入れているか
- [ ] 申込フォームの**個人情報の取り扱い**（利用目的・第三者提供）
- [ ] パートナー契約書（第6条 契約期間）に、**「申し出た月の翌月末で満了」**を反映すること（画面はこの運用で動いています）
