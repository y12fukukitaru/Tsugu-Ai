# 顧問契約書に足す「お支払いが遅れたときの利用の一時停止」の条文（案・仮）

2026-10-15 作成。画面とデータベースでは、次のとおり動きます（`supabase/migrations/20261015020000_suspension.sql`）。

- 期日を過ぎて入っていない顧問料が **3か月分** たまったら、**その翌月の1日から** ご利用を一時停止する
  （例：7月・8月・9月分が未入金 → 10月1日から）
- 停止中も、ログインすると **未入金の内訳・お振込先・担当パートナー** は見られる。ほかの画面は使えない
- **データは消さない**（停止するだけ）
- 入金を記録して、たまった顧問料が3か月分を下回れば **その場で再開** する
- 運営は理由を記録して、**その月だけ** 停止を解くことができる
- **2か月分たまった時点** で、お振込みのお願いのメールに「もう1か月分で翌月1日から一時停止」と書く。
  停止した日に、ご本人と担当パートナーへメールで知らせる
- 顧問料が3か月分たまった方には、月の請求も止める（止めた月はさかのぼって請求しない）

いまの顧問契約書（運営画面の雛形）は、第5条（契約期間・解約）に期間と解約しかなく、
**お支払いが遅れたときに利用を止める定めがありません**。定めが無いまま止めると、
「契約どおりのサービスを受けられなかった」と言われるおそれがあります。
以下の案を、**弁護士の確認を受けてから** 雛形に足し、すでに結んだ方には変更のお知らせと同意をいただいてから使ってください。
**法的な有効性は弁護士の確認を受けてから使ってください（仮）。**

---

## 第5条の2（お支払いが遅れたときの利用の一時停止）

1. 乙（お客様）が、支払期日を経過してもなお支払われていない顧問料が3か月分に達したときは、甲（株式会社福來）は、その翌月の初日から、乙による本サービスの利用（乙が招待した閲覧メンバーによる利用を含む）を一時停止することができる。ただし、未払いの顧問料の内訳、振込先その他支払いに必要な情報の閲覧はこの限りでない。
2. 甲は、前項の一時停止に先立ち、未払いの顧問料が2か月分に達した時点で、乙の登録の電子メールアドレスへ、未払いの額および一時停止の予定日を通知する。また、一時停止を開始した日に、その旨を同アドレスへ通知する。
3. 甲は、未払いの顧問料が支払われ、未払いの額が3か月分を下回ったことを確認したときは、遅滞なく一時停止を解除する。甲は、乙から支払いの予定の申し出があった場合その他甲が相当と認める場合には、一時停止を解除することができる。
4. 一時停止の期間中も、本契約は存続し、甲は乙のデータを消去しない。ただし、甲は、第1項の状態が続く期間の顧問料を請求しないことができる。
5. 第1項の一時停止は、甲による本契約の解除（第◯条）を妨げない。一時停止により乙に生じた損害について、甲は責任を負わない。

## 確かめてほしい点（弁護士の方へ）

| 項目 | 画面の動き | 確認したいこと |
| --- | --- | --- |
| 止める時期 | 3か月分の滞納の翌月1日 | 催告の期間として足りるか（2か月分の時点で事前通知） |
| 止める範囲 | お支払いに関わる表示のほかは使えない | 閲覧メンバー（同じ会社の方）も止めてよいか |
| 止めた期間の顧問料 | 請求しない（さかのぼらない） | 第4項の書き方でよいか |
| 解除との関係 | 止めるだけで、解除はしない | 何か月で解除できるとするか（第◯条の新設が要るか） |
| 既存のお客様 | 雛形を差し替えても、結んだ契約は変わらない | 変更の通知と同意の取り方（約款の変更の扱いになるか） |
| 損害の免責 | 第5項 | 消費者契約法の適用は無い前提（法人・個人事業主）で足りるか |
