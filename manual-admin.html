パートナー

一覧・稼働モニタと、2名体制の承認

一覧・稼働モニタ

登録パートナーの稼働状況を確認します。名前・メールで絞り込めます。

ランク（fde_rank）の設定はここで行います。ランクは外注費率に直結するため、未設定のままにしないでください。

2名体制（サブ担当）の申請

メイン担当が申請した体制が届きます。報酬配分はメイン担当が決めています。

承認するとサブ担当がその顧客を閲覧でき、配分が報酬計算に反映されます。回答メモを添えて承認または見送り。

サブ担当がまだTsuguAIに登録していない場合は「本人のログイン後に有効化されます」と表示されます。その状態でも承認して構いません。本人が初回ログインした時点で自動的に紐づきます。
承認の判断材料：申し送りに引き継ぎの意図が書かれているか、配分が極端でないか（例：サブ90%）。実態と合わない配分は、後で報酬トラブルになります。
顧客

顧客一覧と、役割の変更

顧客 一覧・管理

会社名・メールで検索、担当未割当での絞り込みができます。担当未割当の顧客は放置されやすいので、定期的に確認してください。

アカウントと役割の管理

登録されているすべてのアカウントの一覧です。役割の変更はここでのみ行えます。

役割を誤って変更して一覧から消えた場合も、ここで正しい役割に戻せば復旧します。

顧客の業種は、担当パートナーが顧客カルテの「会社情報（代行入力）」で登録します。専門家ネットワークの業種分布に集計されるので、未設定が多い場合はパートナーに登録を促してください。
専門家ネットワーク

誰がどの領域を実行でき、どこが手薄か

① 領域ごとの実行体制

パートナーの保有資格と提携専門家を合算し、領域別の人数を表示します。
3名以上緑　1〜2名通常　0名対応者なしとして赤で警告

赤い領域から埋めていくと、パートナーが困る場面を先回りできます。

② 顧客の業種分布

業種別の件数と、未設定の件数を表示します。

未設定が多いと、業種に強い専門家を当てられません。件数が目立つときはパートナーへ登録を依頼してください。

この2つはパートナーの資格登録（本業と連携）と顧客の業種登録（カルテ）が入力源です。どちらも現場が入れるものなので、入力率そのものが運営の管理指標になります。
専門家ネットワーク

③ 提携専門家の名簿と、紹介料の考え方

ここに登録した専門家は、パートナーの「本業と連携」画面に表示されます。

氏名・事務所名担当者名と、所属する事務所・法人名。
領域・対応エリア8領域から選択。エリアは「全国（オンライン可）」なども可。
通常の料金 必須目安のない紹介は顧客に勧められないため、入力しないと登録できません。
運営が受け取る紹介料例：初年度報酬の10%
依頼者への還元紹介料を全額値引きに回した後の価格を入れます。ここが空だと、パートナー画面には通常料金だけが出ます。
紹介時の注意・得意分野例：医療法人の持分対策に強い。着手前に必ず見積書を出してもらう運用。
方針：紹介料は運営の利益にせず、依頼者への値引きとして全額お返しします。パートナー画面では通常料金に取り消し線が入り、TsuguAI経由の価格が強調されます。この方針が明示されていないと、パートナーは「運営が中抜きしている」と疑って紹介を止めます。

経営計画

資金調達の記録と、成長ロードマップ連動

調達（融資・出資）を実行したら、必ずここに記録してください。ダッシュボードの成長ロードマップが自動で拾います。

  1. 「経営計画」→ 資金調達リストに項目を追加
  2. 金額は百万円単位で入力1,000万円なら「10」、5,000万円なら「50」。桁を間違えるとロードマップの判定が狂います。
  3. 状況を「実行中」または「完了」にするこの状態のものだけが調達実績として集計されます（「申請中」「審査中」は計画扱い）。
成長ロードマップのステージ3「シード調達」は累計5,000万円で達成判定です。ステージ2「初期トラクション」はパートナー10名・顧問先10社・MRR50万円が目安になっています。
DD（デューデリジェンス）で参照される箇所でもあるため、実行のたびに記録しておくと後から遡らずに済みます。

課金・契約 ①概要

顧問料の割引ロジック

3つの割引を合算し、上限で頭打ちにしてから顧問料に適用します。

A. 契約社数による割引

2〜4社：3%
5社〜：5%
※ カルテの「契約社数」

B. HD化ボーナス

HD化経験あり：5%
※ カルテの「HD化を経験済み」チェック

C. 担当パートナーの階層付与

シニア：2%
エグゼクティブ：5%（顧問5件＋HD化1件）
プレミアム：10%（顧問10件＋HD化2件）

割引率 = A + B + C　→　min(合算, 上限10%)　→　顧問料 50,000円 × (1 − 割引率)
例：契約3社(3%) ＋ HD化(5%) ＋ シニア(2%) = 10% → 上限ちょうど → 45,000円/月
上位ランクが条件未達の場合は、条件を満たす下位の率が付与されます（例：エグゼクティブだが顧問3件なら、シニアの2%）。上限を超えた顧客は画面上で分かるように表示されます。
課金・契約 ④決済リンク

Stripe決済リンクの登録

Stripeで作成したPayment Linkを登録すると、顧客・パートナーの「お支払い」メニューに即時表示されます。

  1. Stripe側でPayment Linkを作成する作り方は納品資料「Stripe課金セットアップ手順」を参照。
  2. 「対象」で顧客またはパートナーを選ぶ
  3. 対象顧客を指定するか、「全顧客共通」にする特定の会社を選ぶと、その顧客にだけ表示されます。割引後の金額別リンクを割り当てるときに使います。
  4. 名称・URL・説明を入れて追加名称は顧客がそのまま読むので「月額顧問料（50,000円/月）」のように金額を含めると親切です。
割引を適用した顧客には、必ず専用リンクを割り当ててください。全顧客共通リンクのままだと定価で決済されます。割引率は③顧客別タブで確認できます。

Stripe自動記録

Webhook経由で自動的に記録されます。顧問料・会費に計上。

メールアドレスから顧客／パートナーを判定して表示します。

手動記録

M&A成約フィー、終活・相続、保険関連などStripeを通らない入金を登録します。

入金日・区分・金額・対象顧客・相手先・摘要。

対象顧客を必ず選んでください。顧客にひも付いていない入金は、次ページの報酬配分で計算対象外になります（誰の担当か決まらないため）。件数と金額は画面に警告として表示されますが、遡って直す手間が発生します。

課金・契約 ⑤報酬配分

3つの警告と、その意味

ランク未設定・個別設定

率が決まらないため報酬0円として計算し、対象者を名指しで警告します。

Lv.1アソシエイトは必ずここに出ます。個別に金額を決めて支払ってください。

顧客ひも付けなしの入金

件数と金額を表示します。誰の担当か決まらないため配分できません。

手動記録で対象顧客を選び直すと計算に含まれます。

担当パートナーなしの顧客

入金があっても配分対象外です。金額を表示します。

顧客に担当を割り当ててください。

計算結果は保存されません。現在のランクと配分で毎回計算し直す仕組みです。支払い確定後にランクや配分を変更すると、この画面の数字も変わります。確定額は必ず運営の帳簿（会計側）で管理してください。この画面は支払額を決めるための参照であり、支払記録ではありません。
運用

月次の締め ― 実行順序

  1. 入金をすべて記録するStripeは自動。M&A成約・保険・終活などStripe外の入金を手動記録。対象顧客を必ず選ぶ。
  2. パートナーのランクを確認・更新する「パートナー」欄。昇格があれば先に反映しないと、報酬計算が旧ランクのままになります。
  3. 2名体制の申請を処理する未承認のまま月をまたぐと、サブへの配分が発生しません。
  4. 報酬配分を計算する「課金・契約」→ 入金タブ → 年月を選択 →「パートナー報酬の配分」。3つの警告をすべて解消する。
  5. 確定額を帳簿に転記して支払うインボイス登録番号は各パートナーが設定画面で登録しています（支払通知書に記載）。
  6. 売上目標・実績を確認する⑥タブで年間目標に対する進捗を確認。

監査ログ・お知らせ配信・サポート管理

監査ログ

操作履歴が記録されます。コンプライアンス対応や、トラブル時の事実確認の証跡になります。

お知らせ配信

顧客向け・パートナー向けに一斉配信。各ポータルのダッシュボード上部に表示されます。

サポート管理

パートナーからの問い合わせの受信箱と、運営サポートAIのナレッジ管理。

サポートAIのナレッジは必ず登録してください。運営ルール・報酬規程・申請手順を登録しておくと、AIがその内容に基づいて回答します。未登録の場合、AIは運営固有の事項を推測で答えず、問い合わせを案内します（誤情報を防ぐための仕様です）。「有効」のものだけが読み込まれます。
最後に

運営として押さえておくこと

ランクの未設定を放置しない

報酬計算が0円になり、毎月手作業が発生します。パートナー登録時に必ず設定を。

手動記録の顧客ひも付けを省略しない

配分から漏れます。後から直すより、記録時に選ぶ方が確実です。

専門家名簿の料金は必ず最新に

顧客に開示される情報です。実際と違うと、パートナーの信用が傷つきます。

紹介依頼を溜めない

パートナーは顧客に「聞いてみます」と言った状態で待っています。

規程の改定予定：「認定パートナー 禁止行為ガイドライン」のうち、有資格のパートナー本人が実行してよいかという論点は現在改定を検討中です。弁護士レビューが完了するまでは現行の定めが適用され、画面上もそれに合わせた表現になっています。レビュー完了後、システム側の表示を一括で切り替えます。
